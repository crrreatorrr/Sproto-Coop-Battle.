# Authored combat sprites

`sprite-timeline.js` is a reusable presentation timeline. Callers supply simulation age; it owns no wall clock, combat event, damage or networking. A clip specifies cell dimensions, an anchor, positive integer frame durations and atlas pages. Explicit `cells` support noncontiguous/shared frames. Finite states clamp to their final cel; movement and rush can loop. The same snapshot therefore selects the same frame in local, relay and banked online play.

`sprite-clip-player.js` streams the current and next page through an owner callback. A late decode retains a complete prior cel from that same state. Encounter/state/phase changes and age rewinds discard that held cel, allowing the owner's new fallback sheet to draw. The player checks page dimensions and disables canvas smoothing. It does not add gameplay effects or alter projectile origins.

The boss adapter selects actions from serialized `st`, `t`, `ph`, `ar`, `row`, `mi` and `su` fields. Fire releases retain their exact 30/38/46-tick boundaries. Charge has a 24- or 36-tick windup and a rush loop. Near the existing 34-pixel stop threshold, a short braking clip uses position-derived age `(34 - remaining) / 8.5`, clamped to 0–4; it works directly for late snapshots. Summon uses post-spawn `su`; death has 151 simulation ticks. Hurt tint accompanies the current attack rather than interrupting its release pose. The `animations` member of `CoopBossTransformations` stores the combat registry alongside transformation metadata, avoiding another startup request. The registry remains empty until reviewed art is installed.

`AssetLoader.setActionPages` owns at most two action pages independently of transformation playback. Both owners suppress next-boss prefetch while active. Phase one may retain one transformation standby page alongside its action stream. Stage changes release both old streams. The fallback actor/projectile sheets remain stage-pinned. Transfer and decoded residency must be measured for the complete art set.

`tools/pack-sprite-clips.py` accepts a JSON specification with `id`, `assetPrefix`, `cell`, `anchor` and a `clips` dictionary. Each clip has complete authored `frames` (`file`, `ticks`) and an optional boolean `loop`. It deduplicates exact RGBA cels across actions, packs bounded lossless WebP pages (default 24 unique cells, 8 columns), verifies exact decoded RGBA including transparent pixels and exports explicit source-cell runs. It generates no poses. Page filenames hash encoded content, including layout. Use `allowRepeatedSources` in the timeline for clips revisiting a shared page.

`npm run build` adds a deterministic release version to startup scripts and exposes it before they execute. The same version is used for image and lazy-script URLs. This keeps cached older atlases/scripts from appearing beside new transformations. The build manifest records actual generated-index bytes/hash plus its source bytes/hash, while public-tree fields continue to describe source inputs. Budget accounting includes the generated HTML overhead. Unbuilt development serving retains canonical URLs. The browser cache test deliberately leaves immutable old images cached, then verifies that the new release fetches replacement pixels through a new URL.

This is presentation architecture. Pinned simulation files and their hub fingerprint remain unchanged.
